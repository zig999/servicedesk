ServicedeskN1 — Modelo de Domínio

Do roteiro de investigação (Case / Hypothesis) à execução (Investigation)

1. Vocabulário

O glossário compartilhado que todo o resto referencia.

Concept — observação nomeada que uma hipótese pode coletar (ttl de frescor, subject types aceitos).
Termos de apoio (sem caixa própria): Subject Type, Subject Attribute, Action, Outcome, Recipient.

2. Roteiro de Conhecimento

O que é definido antes de qualquer execução — casos e hipóteses versionados.

Case identidade → Case Version conteúdo versionado
Hypothesis identidade → Hypothesis Revision critério / coleta / resolução
Case Version compõe várias Hypothesis Revisions, em ordem (Manifest Entry).
Hypothesis Revision coleta N Concepts.

3. Integração

Como uma observação é obtida no mundo real.

Capability — responde exatamente 1 Concept.
Connector Configuration — configuração nomeada que uma Capability referencia (ligação lógica, sem FK garantida no banco).

4. Execução

O que acontece quando um Case roda de fato, contra um Subject real.

Investigation — uma execução, pinada em 1 Case Version, sobre 1 Subject.
Evidence — o que cada Capability retornou para um Concept.
Evaluation — veredito de cada Hypothesis (confirmed / refuted / inconclusive).
Citation — evidência específica que sustenta um veredito.
Assessment — resultado final (outcome + referral).

5. Diagrama de relações

Case ──1:N── Case Version Case ──1:N── Hypothesis ──1:N── Hypothesis Revision Case Version ──N:M── Hypothesis Revision (via Manifest Entry, ordenado) Hypothesis Revision ──N:M── Concept (collects) Capability ──N:1── Concept (answers) Capability ┄┄0..1┄┄ Connector Configuration (nomeia, sem FK) Investigation ──N:1── Case Version (pinned) Investigation ──1:N── Evidence ──N:1── Capability └─N:1── Concept Investigation ──1:N── Evaluation ──1:N── Citation ──N:1── Concept Investigation ──1:1── Assessment

Legenda: linha cheia = FK garantida no banco · linha tracejada = referência lógica sem FK (Capability ↔ Connector Configuration).

Nota: "Simulation" não é uma entidade — é um fluxo efêmero que reusa o mesmo pipeline (Subject → Evidence → Evaluation → Assessment) sem persistir em Investigation.
