## What it is

The second corrective increment of this initiative, over the same defect at a second site: a save control on the capability registration screen that dispatches nothing, and the proof that would have caught it.
It claims the nodes the trace already binds to the file the behavior lives in, plus the nodes that state what a submitted registration does and what abandoning one does not.
It claims nothing about the connector configuration screen, which carries the same defect and follows as its own increment.

## Notes

The claim was seeded mechanically from trace.py --encodes over src/routes/capability-form-fields.tsx, whose output the report carries verbatim.
Three of the eight bindings that output named already read stale before this increment, from the same direct commit that introduced the portal.
The five nodes added beyond that output are disclosed in this epic's own rationale.
