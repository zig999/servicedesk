## What it is

Route-level tests proving draft-capability-schema-from-openapi's three HTTP 422 refusal conditions (an unfetchable link, an unreadable or unsupported document, and an unknown operation), each with its own error value and exact disclosed detail, together with the generic HTTP 500 fallback for an error the status map does not name.
