  extraction.** Every `deliver.py`/`trace.py` invocation issued in this conversation as
  `BIN=<path>; python3 -B $BIN/deliver.py ...` (rather than the literal resolved path) is absent
  from `commands[]` after `2026-09-02T12:23:02.234Z` [record: commands[-1].issued_at], even though

  --bind-record` calls demonstrably ran in this same session — their output is visible directly in
  this conversation's own history, and the commit they produced (`a4d4ece`) exists on disk
  [disk: git log a4d4ece]. If `telemetry.py`'s extractor keys on the literal script path
  (`/bin/deliver.py`) rather than a bare filename match, every `$VAR/deliver.py`-style invocation
  in this session undercounts §4/§5. Evidence: compare `commands[].issued_at` max
  (`2026-09-02T12:23:02.234Z`) against the commit timestamp of `a4d4ece`
  (`2026-09-02T11:10:49-03:00` = `14:10:49Z`) — 1h47m of `deliver.py`/`trace.py` activity this
  session ran is unaccounted for in `commands[]`.
- **[judgment] The `unstated-fact-decider` call is the single most expensive step in the
  `/plan-work` phase (§3.1), by design.** It is not a repeat or a waste — the framework spends its
  most expensive agent tier exactly where a specification silence needs a blind, un-briefed judge,
  and 214s / 1.46M tokens for deciding one durable specification invariant (never revisited) reads
  as proportionate rather than disproportionate.
- **[judgment] Two of five calls in the `/implement-task` phase (§3.2) were collateral-fix
  re-delegations, not the task's own work** — 22% of that phase's token spend went to a lint fix in
  a test-author-authored helper and a pre-existing test the correction legitimately broke. Neither
  is avoidable inside the current contract (each re-delegation pays the full context-read cost from

  widely-shared file (`relational-investigation-store.repository.ts`, bound to 19 nodes per §"bind"
  output) reliably produces collateral breaks whose fix cost is proportional to how many other
  tests exercise that file, not to the size of the fix itself.
