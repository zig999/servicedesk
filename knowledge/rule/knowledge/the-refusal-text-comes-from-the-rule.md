  - Given the rule that a case declares at least one hypothesis, when it refuses a case, then the refusal carries the text that rule declares and no other.
  - Given one rule refusing one case at two positions, when it is validated, then both refusals carry that rule's declared text, each instantiated with its own position.
  - Given a rule no validator can check, when a case is validated, then it declares no text, because it produces no refusal.

## What it is

The curator is the specialist who writes the cases, so the sentence addressed to them is the domain's own language and not a message whatever checks the rule invents.
A text declared by the rule is one text per rule, versioned in the base and reviewable there, where texts written beside the checks would be as many loose strings as there are checks.
Each rule states its text in its own examples, which is the one place a conformance test reaches it and a reviewer can argue with it.
