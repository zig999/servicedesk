## What it is

The behavioral pinning of the exact-comparison glossary reading — every criterion, every recorded inference, and each named accident the binding found the criteria let through, exercised over arranged glossaries holding only placeholder names, at src/__tests__/unit/glossary/lookup.spec.ts.

## Notes

Every glossary these tests hand the lookup is arranged data of placeholder names, so no member of any open vocabulary is stated in the suite.
The spec runs under node:test like every spec beside it, which departs from the standard's STK-10 naming Vitest — introducing Vitest in one file would itself have added the second runner the rule forbids, and the tree holds no manifest to resolve it.
Only the case-normalisation UNDERDETERMINED note appears in the task file as it stands; the phantom-kind and five-kinds exclusions were supplied from an earlier version of the notes, and their tests stand on the base's own refusals either way, disclosed in untested.
